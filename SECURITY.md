# Security reporting / Сообщения об уязвимостях

**English** · [Русский](#russian) · [Overview](README.md)

Guard is a prototype. No supported production release series, guaranteed response time, independent audit or certification is announced here.

## Report privately

Email **[r.galizyanov@spaceai.ru](mailto:r.galizyanov@spaceai.ru?subject=SpaceAI%20Guard%20security%20report)** with the subject `SpaceAI Guard security report`. Send a brief description first; ask for a suitable confidential transfer channel before sending sensitive artifacts.

Include the affected commit, OS/backend, sanitized policy, minimal reproduction, expected boundary and observed impact. Use synthetic credentials. Do not include active secrets or customer data.

Please do not publish exploitation details in a public issue or pull request while arranging a private report. Ordinary bugs can use the [issue forms](https://github.com/SpaceAI-UAG/LLM-agent-security/issues/new/choose).

See the [documented boundaries](docs/usage.md#limitations) before evaluating the prototype.

## Русский

Guard — прототип. Поддерживаемая линейка production-релизов, гарантированное время ответа, независимый аудит и сертификация здесь не заявляются.

### Закрытое сообщение

Напишите на **[r.galizyanov@spaceai.ru](mailto:r.galizyanov@spaceai.ru?subject=SpaceAI%20Guard%20security%20report)** с темой `SpaceAI Guard security report`. Сначала отправьте краткое описание; перед передачей чувствительных материалов согласуйте подходящий конфиденциальный канал.

Укажите commit, ОС/backend, обезличенную политику, минимальные шаги воспроизведения, ожидаемую границу и наблюдаемые последствия. Используйте синтетические ключи; не отправляйте действующие секреты и данные заказчиков.

При организации закрытого сообщения не публикуйте детали эксплуатации в открытом issue или pull request. Для обычных ошибок доступны [формы issues](https://github.com/SpaceAI-UAG/LLM-agent-security/issues/new/choose).

Перед оценкой прототипа изучите [описанные ограничения](docs/usage.ru.md#limitations).
