# Примеры guard-iyr

1. Обычная задача: четыре низкие оценки разрешают передачу.
2. Подмена инструкций: высокая оценка даёт block или flag по policy.
3. Крайний случай: русскоязычная инструкция сохраняется при подготовке JSON.
4. Крайний случай: неполный ответ или отсутствующий вопрос запрещает передачу.
5. Ошибка: API 429, отмена или переадресация запрещают передачу даже при flag.
6. Ключ в env_allow harness/MCP: policy отклоняется.
7. allow_remote отсутствует: Jev не включается.
8. Диагностика: guard evaluate выводит восемь оценок без запуска основной LLM.

Локальный классификатор ранее показал ложное срабатывание на коротком маркере
MCP. Этот случай оставлен в диагностике, исключений по строкам нет.
